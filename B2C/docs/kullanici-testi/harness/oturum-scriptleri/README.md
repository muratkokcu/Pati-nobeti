# Oturum script'leri

Personaların uygulamayı kullanırken gerçekten çalıştırdığı script'ler, çalıştırılma
sırasına göre persona başına tek dosyada birleştirildi. Bir bulgunun nasıl üretildiğini
adım adım görmek için kullanılır; her `// ===== ad =====` bloğu ayrı bir çalıştırmadır.
`koordinator.js`, test başlamadan önce harness'ın doğrulandığı keşif oturumlarıdır.
