# Mobile App Idea Lab

Bu çalışma alanında B2B ve B2C ürün araştırmaları birbirinden ayrılmıştır.

- [B2C — PatiNöbeti / PetShift](B2C/README.md)
- [B2B — SahaKanıt / FieldProof](B2B/README.md)

Aktif öncelik **B2C PatiNöbeti** fikrinin 30 günlük problem, aktivasyon ve ödeme
doğrulamasıdır. Her iki fikir de başarı/öldürme kriterleri geçilmeden geniş ürün
geliştirmeye alınmaz.

Çalışan yerel B2C mobil MVP `apps/mobile` altındadır. Güncel kapsam, doğrulama
sonuçları ve beta kapısı [MVP uygulama durumunda](B2C/docs/07-mvp-uygulama-durumu.md)
tutulur.
